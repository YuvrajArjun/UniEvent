UniEvents — Brand Assets
=========================

unievents-mark.png      The "U" mark only (transparent). Used in the top bar,
                         auth modal, hero badge, page loader, and 404 page —
                         anywhere the logo needs to sit small and compact.

unievents-text.png      The script wordmark only, "UniEvents" (transparent).
                         Used next to the mark in the top bar brand lockup.

unievents-full.png      Full lockup — mark + wordmark + tagline
                         ("The Heartbeat of Campus Experiences.") — transparent.
                         Used in the footer and as a faint hero watermark.

unievents-favicon.png   256x256 favicon derived from the mark, used in <link rel="icon">.

All four are on-brand assets in maroon / gold / cream only, matching the
site's color system (see css/styles.css :root tokens).
