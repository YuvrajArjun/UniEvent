Product Vision

One directory instead of a dozen group chats.

UniEvents exists because campus events currently live scattered across posters, WhatsApp forwards, and departmental notice boards. It brings discovery, registration, and the paperwork of running a student-led event into a single, unified flow — so a student proposing a hackathon and an administrator reviewing it are looking at the same source of truth, in real time.

This build is a complete full-stack implementation: a Django + MySQL backend now powers every proposal, approval token, and registration receipt you generate here — nothing shown on screen is mock data.
